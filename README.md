# Here is the client side of the trip management system!

This system helps school staff manage a trip for students.
Students and teachers register for the trip through the system,

<img width="534" height="316" alt="image" src="https://github.com/user-attachments/assets/ca751371-6da7-4430-8fd4-04f482b2ee45" />

During the trip, students have location devices that send their location to this system,
Teachers can log into the app and see the students' location.

# Installation & Run
  Clone the repository and install dependencies:<br />
  git clone https://github.com/sara-grinshtein/trip-management-system-client.git<br />
  cd trip-management-system-client<br />
  npm install<br />
  npm start<br />
